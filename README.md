# WTKillOverlay

一个 Windows 《战争雷霆》陆战击杀提示程序 MVP。

它只读取游戏在本机暴露的 `http://127.0.0.1:8111/hudmsg` 消息，不读取游戏内存、不注入 DLL、不修改游戏文件，也不显示敌方位置。请在公开传播前自行确认 Gaijin 最新规则；本项目不保证第三方软件永远被允许。

## 已实现功能

- PySide6 可视化主界面与系统托盘
- 监听 `8111/hudmsg`
- 按玩家昵称和可编辑关键词判断本人击杀
- 1～5 杀分别设置素材
- 支持 PNG/JPG/WebP、GIF、MP4/WebM/MOV/MKV/AVI
- 支持 WAV/MP3/OGG/FLAC 音效
- 每档单独设置启用、显示时间、音量、缩放、绿幕/黑幕抠像
- 可视化拖动图标位置
- 多显示器选择、全局大小与透明度
- 内置模拟预览和 1→5 连续演示
- 配置自动保存到 `%LOCALAPPDATA%\WTKillOverlay`
- 用户素材自动复制到应用数据目录
- 日志页面
- PyInstaller Windows 打包脚本
- 基础单元测试

## 运行环境

推荐：

- Windows 10/11 64 位
- Python 3.11 或 3.12 64 位
- 战争雷霆使用“无边框全屏”或“窗口化”；独占全屏通常无法被普通透明窗口覆盖

## 第一次运行


```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

## 素材设置

在“连杀素材”页面，每个等级可以设置：

- 图片、GIF 或视频
- 单独音效
- 显示时间
- 音量
- 等级缩放
- 无抠像、绿幕抠像或黑幕抠像

说明：

- `显示时间 = 0`：视频按完整时长播放；图片/GIF 使用默认时间。
- 普通 H.264 MP4 一般没有透明通道，会显示矩形背景。
- 建议优先使用透明 PNG、透明 GIF、带 Alpha 的 WebM；也可用纯绿或纯黑背景视频配合抠像。
- 短视频建议 512×512 或 640×640、30 FPS、0.8～2 秒。
- 新击杀会立即中断上一段素材并播放新的连杀等级。

## 击杀识别逻辑

程序会在 HUD 消息中查找：

1. 你的玩家昵称；
2. 昵称必须出现在击杀关键词之前；
3. 消息中必须包含任一击杀关键词。

默认关键词包含：

- 摧毁了、击毁了、消灭了、击杀了
- destroyed、killed、set afire
- уничтожил、уничтожила

不同客户端语言、游戏版本或特殊击杀消息可能不同，所以必须通过日志按实际消息调整。


## 已知限制

- `8111/hudmsg` 没有稳定、完整的官方 OpenAPI 文档，字段或文本可能随版本变化。
- 本人击杀依赖本地化文本；首次使用需要根据日志调关键词。
- 视频第一次播放需要解码，较大的素材可能出现短暂延迟。
- 当前缓存适合少量短视频，不建议导入超长或 4K 视频。
- 视频音轨不会播放；请另外选择音效文件。
- 普通透明窗口通常不能覆盖独占全屏。
